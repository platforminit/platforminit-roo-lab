# PlatformInit Docs Operator Rules

## Mission

Write operator-grade docs that let a human safely run and recover PlatformInit.

## Style

- WSL-first.
- Copy-paste-ready commands.
- No PowerShell/CMD.
- No vague "run the workflow" without exact workflow/input names.
- Include expected output and stop conditions.
- Label assumptions.

## Required sections

```text
Purpose
Scope
Prerequisites
Commands
Expected output
Failure modes
Recovery
Related docs
```
