# PlatformInit Roo Lab

This repository is a full-access development rehearsal repository for PlatformInit Roo Code workflows.

It may modify, break, rebuild, or replace the development environment:

- Target host: platforminit-dev-01
- Scope: development only
- Stable recovery source of truth: platforminit-platform
- Production/customer environments: out of scope

The repository exists to validate Roo Code task orchestration, batch execution, review handoff, workflow refactoring, and full recovery from a broken dev state.

If this repository breaks the dev host, recovery must be performed from the stable platforminit-platform repository using the documented CH01-CH05 rebuild chain.
